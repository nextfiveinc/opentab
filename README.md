# Open Tab

Free, working web apps and games without any sign-up or installation requirement.

**[opentab.nextfive.in](https://opentab.nextfive.in)**

A collection of browser apps and games you can open and use right away. Many of them
were built with AI. Every listing says where it was found and when it was last seen
working. New apps are added every week.

## What gets listed

- Web apps and games that run in a browser tab and are free to use. A free tier counts.
  There's nothing to download, and you don't pay before you can try it.
- We leave out apps that are only a chat box on top of an AI model, and anything to do
  with gambling, adult content or scams.
